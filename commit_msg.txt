feat(extension): migrate UnLikeIt from Tampermonkey userscript to a paid Chrome Extension

This commit represents the foundational shift of the UnLikeIt tool from a public userscript to a proprietary paid Chrome extension.

Key Changes:
- Removed legacy userscript (`unlikeit.user.js`) that relied on Tampermonkey/Greasemonkey.
- Introduced `manifest.json` (Manifest V3) for native Chrome Extension support.
- Refactored core business logic into `unlikeit.js` adapting it to run within the extension sandbox.
- Generated and structured required extension assets (`icons/`).
- Updated internal data management to align with extension storage paradigms rather than standard local storage limits.
- Established UI components as an integrated browser extension overlay instead of simple DOM injection.

This structure locks the project down as a closed-source product, setting up the required architecture for future monetization and license verification logic.
